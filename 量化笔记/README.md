## 一条主线（贯穿所有资产）

```
资产类别  →  策略/因子  →  定价模型  →  回测  →  执行下单  →  风险监控
（你交易啥） （赚钱规律） （算出价值） （历史检验）（程序成交） （盯住亏损）
```

每个资产文件内部也大致按"资产特点 → 策略 → 风控"展开；与资产无关的共用环节（定价数学、回测框架、API、数据分析等）统一放在 `00_通用基础.md`，不在各资产文件里重复。
