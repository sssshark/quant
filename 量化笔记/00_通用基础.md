# 00 · 通用基础（三类资产共用的部分）

这些环节与"交易什么资产"基本无关，是任何量化策略都要走的流水线和工具链。
资产专属的策略与风控见 [01_股票](01_股票.md) / [02_CTA期货](02_CTA期货.md) / [03_期权](03_期权.md)。

---

## 写在前面：量化到底在做什么

量化投资，简单说就是把投资决策**规则化、数据化、自动化**。一个完整的量化业务可以拆成一条流水线：

```
资产类别  →  策略逻辑/因子  →  定价模型  →  回测  →  自动化交易  →  风险监控
（交易啥） （什么时候买卖）（算出值多少）（历史验证）（程序下单成交）（盯住亏损）
```

先选定要交易的资产（**资产类别**），再用数据和数学方法找到"什么时候买、什么时候卖"的规律（**策略逻辑 / 因子**），把规律写成可定价、可计算的模型（**定价模型**），用历史数据验证它是否真的有效（**回测**），接着通过程序自动对接交易所下单成交（**自动化交易系统**），同时全程盯住可能的亏损与风险（**风险监控**）。

---

## 一、资产类别（你交易的是什么）

资产类别指交易标的的大类。不同资产的交易规则、风险特征、可用策略都不同，是量化分工的第一层划分。本目录正是按这一层拆分的。

- **股票（Equity）** — 公司所有权的份额。详见 [01_股票](01_股票.md)。
- **CTA / 管理期货** — 以期货为主、程序化趋势类策略。详见 [02_CTA期货](02_CTA期货.md)。
- **期权（Option）** — 非线性的"权利"合约，高度依赖数学模型。详见 [03_期权](03_期权.md)。

> 三者的关键差异：股票只能做多（A股 T+1）、CTA 多空都能做且与股票相关性低（适合分散配置）、期权收益非线性（交易的往往是"波动率"而非方向）。

## 二、定价模型与数学方法（把规律变成可计算的公式）

有了交易思路，还要能算出"这个合约现在值多少钱"。这一层是量化的数学内核（对期权尤其关键）。

- **PDE 数值方法（偏微分方程）** — 期权定价的经典方程（如 Black–Scholes 方程）是一个偏微分方程，常用**有限差分**等数值方法在计算机上求解。
- **蒙特卡洛（Monte Carlo）** — 用计算机模拟成千上万条标的价格的随机路径，对每条路径算出收益再取平均，得到当前价值。特别适合**路径依赖、高维或结构复杂**的衍生品。
- **时间序列分析** — 研究数据随时间变化的规律，常用 **ARIMA**（建模价格走势）、**GARCH**（建模波动率聚集）等模型。
- **回归模型** — 用线性回归、逻辑回归等刻画"因子"与"收益"之间的数量关系，是因子检验和预测的基本工具。

## 三、自动化交易系统（让程序替你下单）

策略再好也要落地执行。这一层负责把信号转成真实订单，并稳定、低成本地成交。

### 3.1 框架与平台

- **ai-trader / FinRL** — 基于强化学习（让 AI 自己"试错"学交易）的量化框架，属于 AI4Finance 开源生态。
- **Qlib** — 微软开源的 AI 量化投资平台，把数据、因子、模型、回测打通成一条龙，适合做机器学习选股。
- **极星国际版** — 面向期货 / 程序化交易的商业交易软件（国际市场版本）。
- **PyAlgoTrade / Zipline / Backtrader** — 三个 Python 量化框架，既能回测也能驱动交易，社区成熟、上手资料多。
- **QuantLib** — 老牌的金融衍生品定价开源库（C++ 内核，含 Python 接口），是"定价模型"层的常用工具箱。

### 3.2 行情与交易接口（API / 数据源）

- **富途量化（Futu / moomoo OpenAPI）** — 富途证券提供的港美股程序化交易与行情接口，国内个人量化常用。
- **IBKR（Interactive Brokers，盈透证券）** — 全球性券商，API 功能强大、可交易品种极多，是跨市场量化的常见通道。
- **Polygon** — 提供美股、期权等高质量行情数据的 API 服务商。
- **OPRA（Options Price Reporting Authority）** — 美国期权报价的官方整合数据源，所有交易所的期权报价汇集于此。

### 3.3 交易机制与成本

- **maker / taker** — 两种成交角色：maker"挂单"提供流动性，通常手续费低甚至有返佣；taker"吃单"主动成交、消耗流动性，手续费较高。常见做法"多边均以 maker 挂单方式下单"，正是为了省手续费。
- **手续费结构与撮合机制** — 交易所如何收费，以及如何按"**价格优先、时间优先**"把买卖订单配对成交。理解它才能优化下单方式、降低成本。
- **滑点（Slippage）** — 你预期的成交价与实际成交价之间的差距。下单量大或行情快时滑点会吃掉利润，是执行环节最重要的隐性成本之一。
- **REST / Websocket / FIX** — 三种对接交易所的协议：REST 适合下单和查询（请求—应答）；Websocket 长连接实时推送行情；FIX 是机构间标准交易协议，低延迟、高可靠。
- **异常检测与自动风控机制** — 系统实时监控异常行情、异常持仓或程序故障，自动触发限仓、撤单或平仓，防止"程序跑飞"造成巨亏。

## 四、回测框架（用历史检验策略）

回测就是把策略放到历史数据里"重演"一遍，看它过去能不能赚钱、回撤多大。这是上线前的必经关卡。

- **Zipline / Backtrader / vnpy** — 三个开源回测/交易框架。其中 **vnpy** 是国内最流行的，偏重期货和数字货币，自带交易接口。
- **天软 / Wind / 博易** — 国内金融数据与行情终端。**Wind（万得）**是机构标配的数据库；**天软**擅长因子计算与历史数据；**博易**是常用的期货行情交易终端。

> ⚠️ 回测最大的陷阱是**过拟合**——策略在历史上完美，实盘却失灵。所以才需要假设检验、样本外测试来甄别真规律与巧合。

## 五、数据分析方法（验证规律是否可靠）

- **回归分析** — 用回归刻画变量之间的关系，例如某因子能在多大程度上解释收益，是因子有效性检验的基础工具。
- **假设检验（Hypothesis Testing）** — 用统计方法判断一个结论是"真的显著"还是"碰巧出现"。通过 **p 值、t 检验**等判断因子或策略的收益是否站得住脚，避免被随机噪声欺骗。
- **时间序列分析** — 见第二节。在数据分析语境下，它还用于检验序列的**平稳性、自相关性**等，是处理金融时间数据的基本功。

## 六、行业与生态（招聘、竞赛、市场角色）

- **ICPC** — 国际大学生程序设计竞赛。量化机构招聘极看重算法与编程能力，ICPC 成绩是常见的"敲门砖"。
- **Kaggle** — 全球最大的数据科学竞赛平台，常被用来衡量机器学习实战能力。
- **AI4Finance 顶会** — AI 金融领域的开源社区与学术会议（FinRL 等项目即出自该生态），代表 AI + 量化的前沿方向。
- **港美做市商（Market Maker）** — 在港股、美股市场持续提供买卖双边报价、赚取价差的机构，是流动性的提供者，也是期权和高频领域的重要玩家。
- **DMA 通道（Direct Market Access，直接市场接入）** — 让客户订单绕过券商人工环节、直连交易所撮合系统的低延迟通道，机构和高频交易的标配。

## 七、关键名词速查表（通用 + 缩写）

资产专属的术语见各自文件末尾的小速查表。

| 名词 / 缩写 | 含义 |
|---|---|
| **PnL** | Profit and Loss，盈亏。分"已实现"（已平仓落袋）和"未实现"（持仓浮动）。PnL 曲线是评估策略最核心的图。 |
| **Drawdown** | 回撤，净值从高点回落的幅度；Max Drawdown 为最大回撤。 |
| **Maker / Taker** | 挂单方 / 吃单方，决定手续费高低。 |
| **Slippage** | 滑点，预期价与成交价之差。 |
| **FIX** | 机构标准交易通信协议。 |
| **DMA** | 直接市场接入，低延迟下单通道。 |
| **Monte Carlo** | 蒙特卡洛，随机模拟路径做定价。 |
| **quantamental** | 主观判断与量化模型结合的方法。 |
| **CTA** | 管理期货策略，详见 [02_CTA期货](02_CTA期货.md)。 |
| **Greeks** | 期权风险敏感度，详见 [03_期权](03_期权.md)。 |
| **OPRA** | 美国期权官方报价整合数据源，详见 [03_期权](03_期权.md)。 |
| **SVI / Heston / SABR** | 三种波动率曲面建模方法，详见 [03_期权](03_期权.md)。 |

## 学习建议

先从一条主线把流程串起来（**资产 → 因子/策略 → 定价 → 回测 → 执行 → 风控**），再逐个深入。
入门可从开源框架 **Backtrader / vnpy** 跑通一个最简单的均线策略回测开始，最有体感。
（你自己的 [量化 ETF 动量轮动项目](../) 正是"股票/ETF + 动量因子 + 回测"这条线的实践。）
