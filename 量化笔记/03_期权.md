# 03 · 期权（Option）

> 通用的定价 / 回测 / 执行 / 数据分析见 [00_通用基础](00_通用基础.md)。本文件只讲期权**专属**的策略与风控。
> 期权对**定价数学**（PDE / 蒙特卡洛，见 00 第二节）的依赖远高于股票和期货——它的价格由数学模型决定，理解期权绕不开这些模型。
>
> 每个概念按：**一句话定义 → 是什么 / 为什么 → 怎么算 / 机制 → 小例子 → 经验值 / 业界 → 常见坑**。

---

## 一、资产特点

### 期权（Option）是什么

**一句话**：期权是一份"权利"合约——买方付一笔钱，获得在未来某个时间、以约定价格买入或卖出标的的权利（但**没有义务**）。

**是什么 / 为什么**：与股票（直接持有）不同，期权买方买的是"未来按约定价交易的选择权"。到期时如果行权对买方有利，他就行使权利；如果不利，他可以放弃、最多损失当初付的那笔钱；卖方则相反——收了钱、必须履行义务。期权的收益是**非线性**的：标的涨一点，看涨期权可能涨很多（不是等比例），这是它和股票最大的区别。

**怎么算 / 机制**：期权价格（权利金）由五个因素决定：标的当前价、行权价、到期时间、波动率、无风险利率。这五个输入进定价模型（如 Black-Scholes）算出理论价格。

**小例子**：某股票现价 100 元。你花 3 元买一张"1 个月后能以 105 元买入"的看涨期权。一个月后若股价涨到 115 元，你可以用 105 元买入、市价 115 元卖出，每股赚 10 元（扣掉 3 元成本净赚 7 元，收益率 233%）。若股价没超过 105 元，你放弃行权，最多亏 3 元。

**经验值**：期权买方最大亏损限于权利金、潜在盈利可观（看涨）或有限（看跌）；卖方相反，最大盈利限于权利金、潜在亏损可能很大。

**常见坑**：期权带杠杆——花小钱撬动大头寸，赚得多亏得也快（尤其做卖方）。新手常被"亏损有限"误导而重仓买期权，结果权利金慢慢归零。

### 期权价格由什么决定（五个因素）

**一句话**：标的价、行权价、到期时间、波动率、无风险利率——这五个输入共同决定一张期权的理论价格。

**怎么算 / 机制**（各因素的影响方向）：
- **标的价**：对看涨期权，标的越涨、期权越贵；看跌相反。
- **行权价**：看涨期权的行权价越低（越容易获利）越贵；看跌相反。
- **到期时间**：时间越长、期权越贵（有更多时间等到有利行情）；随时间流逝，期权会"贬值"（见 Theta）。
- **波动率**：标的越波动、期权越贵（更有可能涨到 / 跌到有利位置）——这是期权最特殊的价格驱动因素。
- **无风险利率**：影响相对小，利率升、看涨期权略贵。

**经验值**：前三个（标的价、行权价、时间）是确定的、可观察的；波动率是唯一"隐藏"、需要从市场反推的（见隐含波动率）。

**常见坑**：忽视波动率对价格的影响——有时标的没怎么动、期权却大跌，就是因为市场预期波动率下降（俗称"杀波动率"）。

## 二、基本概念

### 看涨期权（Call）与看跌期权（Put）

**看涨期权（Call）**：赋予买方"以约定价**买入**标的"的权利。买 Call = 看多标的。标的涨过行权价，Call 才有价值；涨得越多、赚得越多（理论上无限）。

**看跌期权（Put）**：赋予买方"以约定价**卖出**标的"的权利。买 Put = 看空标的（或为已持有的股票保险）。标的跌破行权价，Put 才有价值；跌得越多、赚得越多（最多跌到 0）。

**小例子**：现价 100 的股票，行权价 100 的 Call 权利金 3 元、Put 权利金 3 元。到期时股价 110：Call 赚 10−3=7 元、Put 亏 3 元。股价 90：Call 亏 3 元、Put 赚 10−3=7 元。股价 100：两者都亏 3 元（权利金归零）。

**经验值**：买 Call 看多、买 Put 看空；卖 Call 看空（或愿意高位卖出持股）、卖 Put 看多（或愿意低位接货）。

**常见坑**：买 Call / Put 看对方向也可能亏钱——方向动了但波动率下降、或时间耗尽，权利金仍可能缩水。

### 权利金（Premium）

**一句话**：期权买方为获得这份"权利"所支付的价格，也就是期权本身的市场价。

**是什么 / 为什么**：权利金 = 内在价值 + 时间价值。内在价值是"如果立刻行权能赚多少"（如标的 105、Call 行权价 100，内在价值 5）；时间价值是"到期前还可能变得更有利的期望值"。随着到期临近，时间价值逐渐衰减到 0。

**小例子**：标的 105、行权价 100 的 Call、权利金 8 元。内在价值 = 105−100 = 5 元，时间价值 = 8−5 = 3 元。若到期时标的仍是 105，时间价值归零、权利金只剩 5 元。

**经验值**：时间价值随到期临近加速衰减（见 Theta），这是买方的敌人、卖方的朋友。

**常见坑**：新手只看"便宜"的权利金买入，没意识到时间在持续侵蚀它的价值。

### 行权价（Strike）、到期（Expiration）与实值 / 虚值

**行权价（Strike）**：合约约定的、未来据以买卖标的的价格。同一标的有大量不同行权价的期权可选。

**到期（Expiration）**：期权有效的最后日期。美式期权到期前任何交易日都能行权；欧式期权只能到期当天行权（国内 50ETF / 300ETF 期权是欧式）。

**实值 / 平值 / 虚值（ITM / ATM / OTM）**：看涨期权，标的 > 行权价 = 实值、相等 = 平值、小于 = 虚值；看跌相反。实值期权有内在价值、虚值没有（纯时间价值）。

**小例子**：标的 100。行权价 90 的 Call 是实值（内在价值 10）、行权价 100 是平值、行权价 110 是虚值。虚值期权最便宜（全靠时间价值），但归零概率也最高。

**经验值**：交易活跃的通常是平值及附近的期权；深度实值 / 虚值流动性差、价差大。

**常见坑**：重仓深度虚值期权博暴利——便宜但大概率归零，长期这么做会亏光。

## 三、隐含波动率

### 隐含波动率（Implied Volatility, IV）

**一句话**：把期权的市场价格倒推回定价模型，反解出的"市场对未来波动率的预期"——是期权市场独有的、最重要的变量。

**是什么 / 为什么**：定价模型（如 Black-Scholes）里，其他四个输入（标的价、行权价、时间、利率）都能直接观察到，唯独"波动率"不知道。做法是：把市场上真实的期权价格代进模型，反解出"这个价格隐含的波动率是多少"——这就是 IV。它反映市场预期：IV 高 = 市场觉得未来会大起大落、期权贵；IV 低 = 预期平稳、期权便宜。

**怎么算 / 机制**：已知权利金和其他四个输入，用数值方法（迭代求解）解出模型里的波动率参数。

**小例子**：某 Call 用历史波动率 20% 算理论值 3 元，但市场实际卖 4 元。反推发现，市场价对应的波动率是 30%——即市场预期未来比历史更波动，IV=30%。

**经验值**：IV 是期权交易的"温度计"。常见现象：重大事件（财报、政策）前 IV 升高（期权变贵）、事件落定后 IV 骤降（"波动率崩溃"，买方即使看对方向也可能亏）。

**常见坑**：在高 IV 时买入期权——之后 IV 回落、期权贬值，即便标的方向看对也亏。期权交易既要看方向，也要看波动率贵不贵。

## 四、希腊值 Greeks

> Greeks 用希腊字母衡量期权组合对各类风险的敏感度，是期权风控与交易的核心。每个字母回答"某个因素变动，期权价值变多少"。

### Delta（Δ）

**一句话**：标的价每变动 1 元，期权价值变动多少——衡量"方向性风险"。

**是什么 / 为什么**：Delta 是期权价格对标的价的一阶敏感度。看涨期权的 Delta 在 0~1 之间（标的涨、Call 跟着涨），看跌期权在 −1~0 之间。Delta 也常被近似理解成"到期时变成实值的概率"——Delta=0.5 的期权大约有一半概率最终有价值。

**小例子**：一张 Delta=0.5 的 Call，标的涨 1 元、期权约涨 0.5 元。要完全对冲这张 Call 的方向风险，需持有 0.5 份标的空头（这叫 Delta 中性）。

**经验值**：实值期权 ｜Delta｜ 接近 1、平值约 0.5、虚值接近 0。

**常见坑**：Delta 会随标的价变化（见 Gamma），不是常数——对冲后标的一动，Delta 就偏离中性、需要重新调仓。

### Gamma（Γ）

**一句话**：Delta 本身的变化速度——即标的价变动时 Delta 会变多少。衡量"价格大幅波动时的加速风险"。

**是什么 / 为什么**：Gamma 是二阶敏感度。Delta 不是固定的：标的越涨、Call 的 Delta 越接近 1。Gamma 衡量这个变化有多快。Gamma 大 = Delta 变得快 = 标的剧烈波动时期权价值会"加速"变化。

**小例子**：一张 Gamma=0.05 的 Call，标的涨 1 元，Delta 会增加 0.05（比如从 0.5 升到 0.55）。

**经验值**：平值、临近到期的期权 Gamma 最大——这种期权在标的小幅波动时价值就会剧烈跳变，风险很高。

**常见坑**：做卖方时高 Gamma 极危险——标的突发大波动时对冲跟不上、亏损加速放大（"Gamma 亏损"是很多期权爆仓的根源）。

### Vega

**一句话**：隐含波动率每变动 1%，期权价值变动多少——衡量"波动率风险"。

**是什么 / 为什么**：Vega 是期权价格对波动率的敏感度（虽不以希腊字母命名）。Vega 为正 = 波动率上升时期权升值、下降时贬值（买方的 Call / Put 都是正 Vega）。期权交易者用 Vega 敞口表达"看涨波动率还是看跌波动率"。

**小例子**：一张 Vega=0.2 的期权，IV 从 25% 升到 26%（+1%），期权升值约 0.2 元。

**经验值**：平值期权 Vega 最大；到期越远、Vega 越大（长期期权对波动率更敏感）。

**常见坑**：买入期权后方向看对、却因 IV 回落（Vega 为正、IV 降→贬值）而亏钱——这就是"买方被杀波动率"。

### Theta（Θ）

**一句话**：时间每过一天，期权因"时间衰减"损失多少价值——衡量"时间风险"，是买方的敌人、卖方的朋友。

**是什么 / 为什么**：期权有时间价值，随到期临近而衰减。Theta 通常对买方为负，表示每过一天期权就贬值一点。临近到期的平值期权 Theta 最负（时间价值快速归零）。

**小例子**：一张 Theta=−0.05 的期权，每过一天价值约掉 0.05 元。持有 20 天、光时间损耗就约 1 元。

**经验值**：卖方靠 Theta 赚钱（每过一天收时间价值），但要承担 Gamma / Vega 风险；买方要和时间赛跑。

**常见坑**：买期权"扛着不动"——方向没大错，但每天 Theta 持续扣血，到期权利金归零。

### Rho（ρ）

**一句话**：无风险利率每变动 1%，期权价值变动多少——衡量"利率风险"，影响通常很小。

**是什么 / 为什么**：Rho 是期权价格对利率的敏感度。利率上升，看涨期权略升值、看跌略贬值。但期权寿命较短（几个月内）时，利率影响微乎其微，Rho 常被忽略。

**经验值**：只有长期期权（几年期）或利率剧烈变动时，Rho 才有意义。

**常见坑**：新手把精力放在 Rho 上——对绝大多数短期期权交易，Rho 是最不重要、可忽略的希腊值。

## 五、波动率曲面

### 波动率曲面（Volatility Surface）

**一句话**：把同一标的所有不同行权价、不同到期日的期权各自的隐含波动率，画成一张三维曲面——它"不是一个平面"，这正是期权定价比股票复杂的地方。

**是什么 / 为什么**：按 Black-Scholes 理论，同一标的的所有期权应共享同一个波动率。但现实中，不同行权价、不同到期日的期权反推出的 IV 各不相同。把这些 IV 画出来是一张起伏的曲面，而非平面。曲面随时间变化，本身就是交易对象（波动率交易）。

**怎么算 / 机制**：曲面的典型形状——同行权价上，IV 呈"微笑"形（深实值和深虚值的 IV 比平值高），叫"波动率微笑"；不同到期日上，近月和远月 IV 不同，构成"期限结构"。

**小例子**：某股指平值期权 IV=20%，而行权价偏离 10% 的虚值期权 IV 可能高达 25%——市场愿意为"极端行情"付更高价。

**经验值**：曲面拟合是期权做市和复杂策略的基础；曲面异常（如局部凹陷）常预示套利机会或风险。

**常见坑**：假设"波动率处处相同"——这是经典模型的简化，与真实市场不符，按它定价 / 对冲会留隐患。

### SVI / Heston / SABR（三种曲面建模方法）

**一句话**：三种把波动率曲面参数化、可外推的数学模型，用于拟合曲面形状、给任意行权价和到期日定价。

- **SVI（Stochastic Volatility Inspired）**：用少量参数（5 个）拟合"波动率微笑"的形状，参数少、直观、易于工业实现，是业界拟合曲面的常用首选。
- **Heston**：随机波动率模型——假设波动率本身也是随机变化的（而非常数），比 Black-Scholes 更贴近现实，能同时刻画曲面和波动率微笑。
- **SABR（Stochastic Alpha-Beta-Rho）**：常用于利率和外汇期权，擅长拟合这些市场波动率微笑的特定形状。

**怎么选**：SVI 偏"经验参数化拟合"（轻量），Heston / SABR 偏"有经济学假设的模型"（更重但更自洽）。实务中看品种和用途选择。

**常见坑**：模型拟合得好不代表外推（给曲面外的行权价定价）可靠——极端行权价的定价仍高度依赖模型假设，不同模型会给出差异很大的结果。

## 六、市场微观结构

### 市场微观结构（Market Microstructure）

**一句话**：研究市场最底层的运行细节——订单流、买卖价差、挂单簿深度、撮合规则、成交延迟等。

**是什么 / 为什么**：传统金融假设"交易瞬时、无摩擦、无成本"，但真实市场有价差、有延迟、有规则。微观结构研究这些"摩擦"如何影响价格和策略。高频和做市策略尤其依赖对微观结构的理解——它们的利润就来自这些细节。

**怎么算 / 机制**：关注买卖价差（bid-ask spread，买一和卖一的差）、挂单簿深度（各价位的待成交单量）、订单到达频率、撮合优先规则等。这些决定了"大单能不能低成本成交""延迟多低才能抢到单"。

**经验值**：流动性好的品种价差窄、微观结构友好；小众品种价差宽、大单冲击大。

**常见坑**：回测里假设"按收盘价全量成交"、忽视真实价差和冲击——实盘会发现成本远高于回测，尤其对高频和期权做市。

## 七、数据与角色

### OPRA（Options Price Reporting Authority）

**一句话**：美国期权报价的官方整合数据源，所有交易所的期权实时报价汇集于此。

**是什么 / 为什么**：美国有十多家期权交易所，同一份期权在各处报价可能略有差异。OPRA 把它们统一汇集，是期权行情的权威来源。做美股期权的数据服务基本都基于 OPRA。

**经验值**：OPRA 数据量极大（每秒海量报价更新），获取和处理它的成本不低，是期权数据基础设施的门槛之一。

### 做市商（Market Maker）

**一句话**：在市场上持续同时报出买价和卖价、随时准备双边成交的机构，靠赚取买卖价差获利，是流动性的提供者。

**是什么 / 为什么**：普通投资者想买时需要有人愿意卖、想卖时需要有人愿意买。做市商就是那个"随时在两边等着"的角色，靠低买高卖（价差）赚微利、积少成多。期权市场尤其依赖做市商——因为期权种类繁多、很多流动性差，没有做市商很难成交。

**怎么算 / 机制**：做市商持续挂出买价（bid）和卖价（ask），卖价略高于买价，差额就是它的毛利；同时管理复杂的 Greeks 敞口（用标的、其他期权对冲 Delta / Vega 等）。

**经验值**：做市是低毛利、高技术含量的生意，靠速度、风控和规模赚钱，是高频交易的重要场景。

**常见坑**：普通投资者和做市商"对赌"通常处于劣势——你看到的报价是它精心设定的，频繁短线交易容易被价差和它的速度优势吃掉。
