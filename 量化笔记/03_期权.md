# 03 · 期权（Option）

> 通用的定价/回测/执行/数据分析见 [00_通用基础](00_通用基础.md)。本文件只讲期权**专属**的策略与风控。
> 注意：期权对**定价数学**（PDE / 蒙特卡洛，见 00 第二节）的依赖远高于股票和期货。

---

## 一、资产特点

**期权（Option）** — 一种"权利"合约：买方付一笔**权利金**，获得未来以约定价格**买入（看涨 Call）或卖出（看跌 Put）**标的的权利，但**没有义务**。

收益是**非线性的**（不像股票涨跌一一对应）。价格由**标的价、行权价、到期时间、波动率、利率**共同决定，因此期权策略高度依赖数学模型。

---

## 二、策略逻辑：期权与波动率策略

期权策略的本质**往往不是赌方向，而是交易"波动率"**。相关概念：

- **市场微观结构（Market Microstructure）** — 研究市场最底层的运行细节：订单流、买卖价差、挂单簿深度、撮合规则等。**高频和做市策略**尤其依赖对微观结构的理解（美股期权做市是典型场景）。

### 波动率曲面（Volatility Surface）

把不同行权价、不同到期时间对应的"**隐含波动率**"画成一张三维曲面。它**不是一个平面**——这正是期权定价比股票复杂的地方。三种常用的建模方法：

| 模型 | 全称 / 特点 |
|---|---|
| **SVI** | Stochastic Volatility Inspired，参数化方法，用少量参数平滑拟合"波动率微笑"，**工业界拟合曲面的常用首选**。 |
| **Heston** | 随机波动率模型：假设波动率本身也是随机变化的（而非固定常数），能更真实地刻画市场。 |
| **SABR** | Stochastic Alpha-Beta-Rho 模型，常用于**利率和外汇期权**，擅长拟合波动率微笑的形状。 |

## 三、风险监控：期权 Greeks 敞口（希腊值）

用希腊字母衡量期权组合对各类风险的敏感度，是**期权风控的核心**，也是波动率交易的操作对象。通常控制在预设限额内：

| 希腊值 | 含义 |
|---|---|
| **Delta** | 标的价格每变动 1，组合价值变动多少（**方向性风险**）。 |
| **Gamma** | Delta 本身的变化速度（价格大幅波动时的**加速风险**）。 |
| **Vega** | 隐含波动率每变动 1%，组合价值变动多少（**波动率风险**）。 |
| **Theta** | 时间每过一天，期权因"**时间衰减**"损失的价值。 |
| **Rho** | 利率变动对期权价值的影响（影响相对较小）。 |

> 希腊值"既是风控工具也是交易标的"：做波动率策略时，你主动调整 Delta/Vega 敞口去表达对波动率的看法。

## 速查表（期权专属）

| 名词 | 含义 |
|---|---|
| Call / Put | 看涨期权 / 看跌期权 |
| 权利金 | 买方为获得"权利"支付的费用 |
| 隐含波动率 (IV) | 由期权市场价反推出的波动率预期 |
| Greeks | Delta / Gamma / Vega / Theta / Rho 敏感度 |
| Volatility Surface | 波动率曲面（行权价 × 到期 × 隐含波动率） |
| SVI / Heston / SABR | 三种波动率曲面建模方法 |
| Market Microstructure | 市场微观结构（订单流、价差、撮合） |
| OPRA | 美国期权官方报价整合数据源（见 [00](00_通用基础.md)） |
